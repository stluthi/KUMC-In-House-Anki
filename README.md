# KUMC-In-House-Anki
University of Kansas School of Medicine in-house lecture Anki decks

**Diclosure:** All cards in the original Anki deck were created and belong to myself. I've attached a GNU-GPLv3 License to this repository to keep it's contents free and out from behind paywalls (i.e. AnkiHub). DO NOT distribute these cards elsewhere or upload them to AnkiHub.

## Organization

I tried to put all blocks in the same deck. However, that turned out to be a 4.5GB .apkg, which is over GitHub's repository limits for a single file. So each block will be released separately. Feel free to combine them into one deck.

The following is the structure of a Block deck:
```
Block 1: MCM
  └── Summative 1
    ├── W1D1 (where W=Week and D=Day)
    ├── W1D2
    ├── ...
    └── W2D3
  └── Summative 2
  └── Summative 3
  └── Summative 4
```
Note: D1-D5 corresponds to Monday-Friday. Some weeks don't have all days. This is normal due to holidays/no lectures/etc. If you see a mistake, let me know ASAP.

There are no third-party resources in these decks. All cards are self-made.

## Installation

1. Download the latest '.apkg.' from Releases.
2. Open Anki.
3. File → Import
4. Select the '.apkg' you just downloaded.
5. Import the deck
6. Verify the deck has 'X' number of cards (future releases).
